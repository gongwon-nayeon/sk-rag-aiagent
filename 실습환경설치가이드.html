필수 설치 프로그램

uv (Python 패키지 관리자) Python 자동 관리

💡 Python 설치 불필요!
uv는 Python 버전을 자동으로 다운로드하고 관리합니다. 별도로 Python을 설치할 필요 없이 uv만 설치하면 됩니다. (교육에서는 Python 3.13.5 자동 사용)

  • PowerShell에서 uv 설치
    PowerShell을 관리자 권한으로 실행한 후 다음 명령어 실행:
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  • 설치 확인: 새 PowerShell 창을 열고 다음 명령어 실행
    uv --version
  • 버전 정보가 출력되면 설치 완료
  • 터미널에서 uv 설치
    터미널을 열고 다음 명령어 실행:
    curl -LsSf https://astral.sh/uv/install.sh | sh
  • 설치 확인: 새 터미널 창을 열고 다음 명령어 실행
    uv --version
  • 버전 정보가 출력되면 설치 완료

uv란? 초고속 Python 패키지 관리 도구입니다. Python 버전 관리, 가상환경 생성, 패키지 설치를 모두 자동으로 처리합니다.

Visual Studio Code

  • 공식 웹사이트에서 VS Code 다운로드 다운로드
  • User Installer 또는 System Installer 다운로드 (User Installer 권장)
  • 설치 프로그램을 실행하고 안내에 따라 설치를 완료합니다
  • 설치 완료 확인: VS Code를 실행하여 정상 작동 확인
  • 필수 확장 설치:
    1. VS Code 왼쪽 사이드바에서 Extensions 아이콘 클릭 (또는 Ctrl+Shift+X)
    2. "Python" 검색 후 Microsoft 제공 확장 설치
    3. "Jupyter" 검색 후 Microsoft 제공 확장 설치
  • 공식 웹사이트에서 VS Code 다운로드 다운로드
  • .dmg 파일을 다운로드하여 엽니다
  • Visual Studio Code를 Applications 폴더로 드래그합니다
  • 설치 완료 확인: Applications 폴더에서 VS Code를 실행
  • 필수 확장 설치:
    1. VS Code 왼쪽 사이드바에서 Extensions 아이콘 클릭 (또는 Cmd+Shift+X)
    2. "Python" 검색 후 Microsoft 제공 확장 설치
    3. "Jupyter" 검색 후 Microsoft 제공 확장 설치

💡 필수 확장: Python과 Jupyter 확장은 Jupyter Notebook 사용을 위해 반드시 설치해야 합니다. (Python 패키지 jupyter, ipykernel은 uv sync 시 자동 설치됩니다)

Git

  • Git for Windows 다운로드 다운로드
  • 설치 프로그램을 실행하고 기본 옵션으로 설치 (특별한 경우가 아니면 변경하지 않기를 권장)
  • 설치 확인: PowerShell 또는 명령 프롬프트에서 다음 명령어 실행
    git --version
  • Git 사용자 설정:
    git config --global user.name "Your Name"
    git config --global user.email "your.email@example.com"
  • 방법 1: Homebrew로 설치 (권장)
    brew install git
  • 방법 2: 공식 설치 파일 다운로드 다운로드
  • 설치 확인: 터미널에서 다음 명령어 실행
    git --version
  • Git 사용자 설정:
    git config --global user.name "Your Name"
    git config --global user.email "your.email@example.com"

참고: Git 사용자 설정은 본인의 실제 이름과 이메일로 변경해주세요.

문제 해결

자주 발생하는 문제

"uv" 명령어를 인식할 수 없습니다

  • uv 설치 후 PowerShell을 재시작하지 않은 경우
  • 해결: PowerShell을 완전히 종료하고 새로 실행합니다
  • 또는 시스템을 재시작합니다

"git" 명령어를 인식할 수 없습니다

  • Git 설치 후 터미널을 재시작하지 않은 경우
  • 해결: PowerShell 또는 명령 프롬프트를 종료하고 다시 실행합니다

uv sync 실행 시 오류 발생

  • 인터넷 연결 문제이거나 방화벽이 Python 다운로드를 차단하는 경우
  • 해결: 인터넷 연결 확인 후 다시 시도합니다

"uv" 명령어를 인식할 수 없습니다

  • uv 설치 후 터미널을 재시작하지 않은 경우
  • 해결: 터미널을 완전히 종료하고 새로 실행합니다
  • 또는 source ~/.zshrc 또는 source ~/.bashrc 실행

"git" 명령어를 인식할 수 없습니다

  • Xcode Command Line Tools가 설치되지 않은 경우
  • 해결: 터미널에서 xcode-select --install 실행

uv sync 실행 시 오류 발생

  • 인터넷 연결 문제이거나 방화벽이 Python 다운로드를 차단하는 경우
  • 해결: 인터넷 연결 확인 후 다시 시도합니다
